# 罗小黑桌宠

Windows 桌宠，使用 Electron、React、Pixi 和 Live2D。

## 互动方式

- 点击头顶、左右脸颊、身体，会得到不同的小动作回应；双击会开心。
- 按住头顶约 0.3 秒，再轻轻左右移动鼠标即可抚摸。小光圈表示正在抚摸，松开后自然恢复。
- 拖动身体移动桌宠；也可以在长按成立前直接拖动头部。锁定位置后仍可点击和抚摸。
- 睡觉时，鼠标经过、点击身体或拖动都不会唤醒；点击头部播放醒来动画。
- 右键打开设置、动作菜单、查看状态或鼠标跟随开关。移动动作可以选择向左或向右走。
- 右键 →「查看状态」可查看实时心情、精力（0–100）和当前活动；关闭按钮、窗口叉号或 Esc 都可收起，平时不常驻显示。查看不会增加心情或唤醒睡眠中的宠物。
- 动作菜单分「常用动作」和「小表情」两页。「小表情」新增点头、摇头、眨眼、害羞、打哈欠和轻轻摇摆，配有随头部缩放的星光、脸红或音符等效果。每次播放一遍后平滑回正，打哈欠不会自动进入睡眠；切换动作时立即清理上一个效果。
- 鼠标跟随开启时，眼睛先看向鼠标，头部随后轻微转动；关闭后平滑回正。

桌宠会缓慢消耗精力，睡眠恢复精力，抚摸改善心情。待机时根据状态眨眼、观察、放松或短暂打瞌睡。精力和心情保存在本机，重启后保留，离线期间适度恢复精力。此版本没有联网聊天。

## 主动陪伴

- 默认「适中」：约隔 5–8 分钟，根据心情和精力自行做一个小动作；「活泼」约隔 4–7 分钟。每小时最多 6 次，避开最近两个动作，间隔和历史会保存。心情好时更常眨眼、点头或轻摆，低落时偏向害羞或轻轻摇头，疲倦时优先哈欠、放松或休息。这些动作不额外弹出邀请框，也不会把它自己的表演算成用户陪伴、给心情加分。
- 表情和邀请共用动作时序：等当前动作结束再开始，表情结束后至少留 45 秒再发起邀请。需要入睡时优先休息。小幅待机观察和呼吸仍保留。
- 约 10–15 分钟没有互动、精神不错且电脑有操作时，可能出现一次小气泡。主动邀请每小时最多两次。
- 可以点击「陪你玩／摸摸头」，也可以直接点击或抚摸头部回应。回应后它会安静陪伴一段时间。
- 不回应时约 8 秒自动收起；首次未回应后邀请至少等 30 分钟，连续未回应后至少等 60 分钟；自主小表情的间隔也分别延长到至少 15／30 分钟。重启保留邀请次数和等待时间。
- 点击「先忙」会安静一小时，新表情和邀请一起暂停。在设置的「主动陪伴」中可以提前恢复，也可以选「安静」关闭主动表情和邀请，或选「活泼」使用约 8–12 分钟的邀请间隔；各档仍有每小时两次邀请上限。
- 至少 20 分钟没有互动且精力降到 35 以下时，会慢慢闭眼入睡。睡着后点击头部唤醒，鼠标经过、身体点击、电脑恢复操作均不会自动唤醒。设置中可关闭「累了自己休息」。
- 手动动作、拖动、抚摸优先；打开设置／动作菜单／状态窗口、隐藏桌宠、鼠标穿透、锁屏时暂停自主行为。系统超过三分钟没有输入时暂停主动表情和邀请，但不据此认定用户已经离开。
- 小气泡不获取键盘焦点，会按宠物大小和屏幕边界定位。启动、锁屏恢复和长时间暂停后留出缓冲，不补发积压的邀请。自主行为不移动桌宠位置。

## 开发与验证

```sh
npm install
npm run electron:dev
```

```sh
npm test
npm run test:e2e
npm run package:win
```

自动测试使用独立配置，不覆盖日常桌宠设置。交互回归覆盖触摸分区、抚摸与拖动冲突、睡眠唤醒、动作打断、实际模型姿态、邀请回应、打扰频率与状态持久化。长时间间隔使用可控时钟验证，模型动作仍按真实帧播放。
